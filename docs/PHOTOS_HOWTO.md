# Как добавить фото товаров (для не-программиста)

Скрипт только превращает готовые картинки PNG или JPG в формат webp для магазина. Сам он ничего не рисует. Папку с вашими картинками он только читает и не меняет.

## 1. Подготовьте папку
Положите готовые картинки в одну папку (любую, например в Загрузки). Назовите файлы так:
- `ID__card.png` — основное фото товара (карточка в каталоге), например `NUT-013__card.png`. Можно и просто `NUT-013.png`.
- `ID__page.png` — второе фото (страница товара), например `NUT-013__page.png`.
Расширение может быть png, jpg или jpeg. ID должен совпадать с колонкой ID в таблице.

Второе фото (page) не делается для: DRY-039, DRY-089, DRY-090, DRY-068, DRY-086, NEW-yabluka-sushka, NEW-sochevytsya-chervona, NUT-048, NEW-garbuzove-golonasinne. Скрипт сам их пропустит и напишет `skip (no page)`.

## 2. Проверка без записи
Скрипту нужна библиотека sharp. В проект она не ставится. Если она уже есть в другом вашем проекте (папка `node_modules\sharp`), укажите путь к ней. Если нет, один раз установите её в отдельную папку: `mkdir $HOME\sharp-tools; cd $HOME\sharp-tools; npm install sharp` (путь тогда `$HOME/sharp-tools/node_modules/sharp`).

Откройте PowerShell в папке проекта и выполните (путь к папке с картинками подставьте свой):

    $env:SHARP_PATH = "$HOME/sharp-tools/node_modules/sharp"
    node tools/photos.js --src "C:\путь\к\папке" --only page

Вы увидите список: какой файл во что превратится, и строку `SUMMARY: would write N`. Ничего не записано.

## 3. Запись
Та же команда с `--write`:

    node tools/photos.js --src "C:\путь\к\папке" --only page --write

- `--only page` — только вторые фото; `--only card` — только основные; без `--only` — всё.
- Уже существующий файл не перезаписывается. Чтобы заменить, добавьте `--force`.
- Для основных фото сразу создаётся маленькая копия (360 px) и добавляется строка в `docs/data/photos_stage9.csv`.
- В конце строка `SUMMARY`. Если есть ошибки, строка покажет `errors` больше нуля.

Готовые файлы лежат в `webapp/img/products/` (основные), `webapp/img/products/s/` (маленькие) и `webapp/img/products/p/` (вторые фото).

## 4. Что делать дальше
1. Попросите главного агента или сами зафиксируйте и отправьте файлы на GitHub (после вашего «да»), чтобы фото появились на сайте.
2. Обновите Code.gs в Apps Script и сделайте New version в Manage deployments (без этого работает старая версия).
3. В таблице откройте меню PAMIR, пункт «Етап 9Б2: записати другі фото». Он создаст колонку «Фото 2» и впишет адреса вторых фото. Уже заполненные ячейки не трогает, повторный запуск безопасен. В конце покажет, сколько записано, сколько уже было и сколько товаров не найдено.
4. Для основных фото: в таблице в колонке «Фото (посилання)» должен стоять адрес вида `https://vorfl.github.io/pamir-shop/webapp/img/products/ID.webp`. Если там пусто, впишите его или используйте пункт меню этапа 9.
5. Выберите в меню «Оновити каталог у магазині зараз» и проверьте товар в магазине.
