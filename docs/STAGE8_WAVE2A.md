# PAMIR — этап 8, волна 2, выпуск 2а: инструкция

Ветка `stage8-wave2a`. Готовы части А1–А5 из `docs/STAGE8_WAVE2_PLAN.md`. Выпуски 2б и 2в не тронуты.

Проверено автотестами на стенде: бэкенд — 313 проверок, витрина в браузере на экране 360 px (светлая и тёмная тема, UA и RU) — 259 проверок. С настоящим Telegram и вашей таблицей ещё не проверялось — это проверка на телефоне ниже.

## Как включить

Порядок важен: **сначала бэкенд (шаги 1–4), потом витрина (шаг 5)**. Новая витрина со старым бэкендом открывается, но кнопки архива и удаления ответят ошибкой.

1. **Отправить код в Google.** Делает Claude по вашей команде: показывает `clasp status` и разницу в `Code.gs`, ждёт вашего «ок», потом `clasp push`.
   Важно: после `clasp push` новый код уже работает в триггерах (ежедневные и ежечасные сообщения клиентам). Поэтому шаг 2 делайте сразу следом, без перерыва.
2. **Обновить деплоймент.** Таблица → Расширения → Apps Script → **Deploy → Manage deployments → карандаш (Edit) у «Telegram webhook…» → Version: New version → Deploy.**
   Новый деплоймент не создавать: у него будет другой адрес, а на текущий ссылается витрина. Без этого шага бот и магазин работают на старой версии.
3. **Script Properties** — новых обязательных нет. Два служебных свойства появятся сами при первом удалении товара навсегда: `DELETED_IDS` и `PRODUCT_ID_MAX`. Не удаляйте их: по ним новые товары не получают ID удалённых.
4. **Листы.** Вернитесь в таблицу, обновите страницу. Меню **PAMIR → «Етап 8.2: створити листи «Архів товарів» і «Клієнти»»**. Шаг необязательный: оба листа появятся сами при первой архивации и первом `/start`.
5. **Витрина.** На GitHub: ветка `stage8-wave2a` → Pull request → Merge в `main`. Витрина обновится через 1–2 минуты.
6. `startPolling()` по-прежнему **не запускать** — он удаляет webhook.

|---|---|---|
| «Архів товарів» | те же колонки, что в «Товари», плюс «Дата архівації» и «Хто архівував» | шаг 4 или сам при первой архивации |
| «Клієнти» | Chat id, Ім’я, Мова, Перший вхід, Останній вхід, Відписка, Заблокував бота | шаг 4 или сам при первом `/start`, заказе или открытии магазина |

Новых колонок в «Товари», «Замовлення», «Категорії» и «Адміни» нет.

## Как это работает (коротко)

- **Кнопки.** После нажатия кнопка сразу показывает вращающийся индикатор и не нажимается второй раз, пока сервер не ответит. Сохранение в панели — «Збережено» с галочкой прямо на кнопке. Переключатель наличия в списке товаров и галочки «В наявності» / «Приховати з вітрини» в карточке товара сохраняются сразу, без «Зберегти»; если сервер ответил ошибкой — возвращаются назад с сообщением.
- **Страницы.** В каталоге 20 товаров на странице. Внизу подпись «Товари 21–40 з 87» и номера страниц. Автоподгрузки при прокрутке больше нет. Подборки на главной (Популярне, Акції и т. п.) не менялись.
- **Товары в панели.** Над списком — чипы категорий и три фильтра с числом товаров: «Немає в наявності», «Приховані», «Без фото». Поиск ищет по всем товарам.
- **Архив.** В карточке товара в панели внизу кнопка «В архів». Товар пропадает с витрины, строка переезжает в лист «Архів товарів». Панель → Товари → «Архів товарів»: у каждого товара «Відновити» (возвращает в конец листа «Товари» с прежними данными) и «Видалити назавжди» (только полный админ и владелец; отменить нельзя).
- **Старые заказы** при архивации и удалении не меняются: в листе «Замовлення» состав записан текстом.
- **«Повторити замовлення»**, если товара из заказа больше нет: он пропускается, в корзине подсказка «Деяких товарів більше немає».
- **«Повідомити, коли з’явиться».** На товар в архиве сообщения не уходят. После «Відновити» подписка снова действует.
- **ID после удаления навсегда.** Новый товар из панели никогда не получит ID удалённого или архивного. Если такой ID вписать в таблицу руками — карточка товара в панели и меню PAMIR → «Перевірити каталог» покажут предупреждение.
- **Категория.** В карточке категории — «Видалити категорію». Пустая удаляется сразу. Если в ней есть товары (включая скрытые), панель просит выбрать категорию, куда их перенести. Товары в архиве категорию не держат.
- **Админ.** В карточке админа — «Видалити адміна». Владельца удалить нельзя, себя нельзя, полных админов удаляет только владелец. Владельцу приходит сообщение в боте.
- **Админы из `ADMIN_CHAT_IDS`.** Помечены «Доданий у налаштуваннях скрипта». Панель их не удаляет: в карточке вместо кнопки — подсказка, где убрать id вручную. Если человек записан и в листе «Адміни», и в `ADMIN_CHAT_IDS`, перед удалением панель предупреждает, что доступ у него останется.
- **Журнал.** Архивация, восстановление, удаление навсегда, удаление категории и админа пишутся в лист «Журнал» с названием и ID.
- **Клієнти.** Строка появляется, когда человек нажал `/start`, сделал заказ или открыл магазин. «Останній вхід» обновляется не чаще раза в 6 часов. «Заблокував бота» = `так`, когда Telegram не смог доставить сообщение; отметка снимается, когда человек вернулся. Колонка «Відписка» пока пустая — она нужна для рассылки в выпуске 2б.

## Что проверить на телефоне

Кнопки (А1):
1. Панель → Замовлення → открыть заказ → нажать статус. Кнопка сразу показывает кружок и сереет, соседние не нажимаются. Быстрое двойное нажатие — статус меняется один раз (в «Журнал» одна строка).
2. Панель → Товари → переключатель наличия. Меняется мгновенно. На витрине товар становится «немає» и обратно.
3. Открыть товар → изменить описание → «Зберегти». На кнопке кружок, потом зелёная «Збережено» с галочкой, потом возврат к списку.
4. В карточке товара поставить галочку «Приховати з вітрини» — сохраняется сразу, появляется «Збережено». Снять.
5. Панель → Налаштування → «Зберегти»: «Збережено» на кнопке, экран остаётся на месте.
6. Витрина: любая кнопка заметно «проминается» при нажатии, телефон слегка вибрирует.

Страницы (А2):
7. Главная → прокрутить вниз «Усі товари»: 20 товаров, под ними «Товари 1–20 з N» и номера страниц в одну строку. Сами товары при прокрутке не подгружаются.
8. Нажать «2»: список прокручивается к своему началу (под чипами категорий), подпись «Товари 21–40 з N», цифра 2 абрикосовая.
9. На странице 2 открыть товар, закрыть кнопкой «Назад» Telegram: та же страница 2, то же место.
10. На странице 2 выбрать категорию, потом поиск, потом фильтр — каждый раз список начинается со страницы 1.

Товары в панели (А3):
11. Панель → Товари: 20 товаров, внизу номера страниц, подпись «Товари 1–20 з N». Надписи «Показано перші 60» больше нет.
12. Чип категории показывает только её товары. Чипы «Немає в наявності», «Приховані», «Без фото» — с числами.
13. В поиске набрать название товара с последней страницы — находится.

Архив и удаление (А4) — на тестовом товаре, не на настоящем:
14. Панель → Товари → «Додати товар», создать «Тест архіву». Открыть его → внизу «В архів» → в окне написано название товара → «В архів: Тест архіву». Товар пропал из списка и с витрины. В таблице появился лист «Архів товарів» со строкой.
15. Панель → Товари → «Архів товарів» → «Відновити». Товар снова в списке и на витрине, в «Товари» строка в конце.
16. Снова «В архів», потом в архиве «Видалити назавжди» → красная кнопка «Видалити назавжди Тест архіву», текст «Це не можна скасувати». После удаления строки нет ни в «Товари», ни в архиве.
17. Создать ещё один товар в той же категории — его ID на единицу больше, старый ID не повторился.
18. Панель → Категорії → «Додати категорію» (например код `TST`) → открыть её → «Видалити категорію» → «Видалити «…»». Пропала.
19. Открыть категорию с товарами → «Видалити категорію»: панель показывает, сколько в ней товаров, и просит выбрать, куда перенести. **Нажмите «Скасувати»**, если удалять её не собираетесь.
20. Панель → Адміни: у админов из `ADMIN_CHAT_IDS` подпись «Доданий у налаштуваннях скрипта», в карточке — подсказка вместо кнопки удаления.
21. Добавить тестового менеджера (второй аккаунт), потом открыть его → «Видалити адміна» → красная кнопка с его именем. Со второго аккаунта панель больше не открывается, вам в бот пришло сообщение.
22. Панель → Адміни → «Журнал дій»: видны архивация, восстановление, удаление.
23. Со второго аккаунта (менеджер с правом «Тексти товарів»): в архиве есть «Відновити», а «Видалити назавжди» нет.

Клієнти (А5):
24. Нажать `/start` со второго аккаунта → в таблице лист «Клієнти», строка с его chat id, именем, языком и датами.
25. Открыть магазин и сделать заказ с третьего аккаунта (или того же) — строка одна, дублей нет.

## Решения, принятые по ходу

| Вопрос | Решение |
|---|---|
| Номера страниц на 360 px | Кнопки по 44 px в одну строку помещаются 7 штук вместе со стрелками. Поэтому до 5 страниц видны все номера, дальше — `‹ 1 2 3 … 9 ›`, в середине — `‹ 1 … 5 … 9 ›` (соседние листаются стрелками). На экране от ~450 px в середине видны и соседние: `‹ 1 … 4 5 6 … 9 ›` |
| «Приховати» как переключатель | В карточке товара галочки «В наявності» и «Приховати з вітрини» сохраняются сразу. В списке остался один переключатель (наличие), чтобы строка не стала тесной |
| Где хранить ID удалённых товаров | Script Properties `DELETED_IDS` (список) и `PRODUCT_ID_MAX` (наибольший выданный номер по категориям). Листов для этого не заводил |
| «Панель предупреждает при создании» | ID в панели выдаётся автоматически и не повторяется. Предупреждение показывается, если ID удалённого товара вписали в таблицу руками |
| Формулы при восстановлении | В архив переносятся значения. При «Відновити» формулы в строке (маржа, цена за 100 г) берутся из строки выше — как при протягивании в таблице |
| Колонки без заголовка | В архив не переносятся (не к чему привязать). У всех рабочих колонок заголовки есть |
| Товар с таким ID уже есть в «Товари» | «Відновити» отклоняется с сообщением, дубль не создаётся |
| Удаление навсегда | Только из архива. Товар прямо из «Товари» стереть нельзя, даже запросом в обход панели |
| Админ, записанный только в `ADMIN_CHAT_IDS` | Панель не удаляет и Script Properties не меняет; показывает подсказку |
| Кто может удалить менеджера | Как при отключении в волне 1: владелец — любого; остальные — только если у удаляемого нет прав, которых нет у них самих. Полных админов — только владелец |
| Подтверждения | Только для заметных и необратимых действий. «Відновити» — без вопроса (обратимо). «В архів» — с вопросом и названием, кнопка не красная. Удаления — красная кнопка с точным названием |
| «Клієнти»: как часто писать | «Останній вхід» — не чаще раза в 6 часов на человека. Заказ записывается всегда и задаёт язык |
| «Клієнти»: админы | Записываются тоже: они такие же получатели сообщений бота |
| «Заблокував бота» | Ставится по отказу Telegram в доставке (403) и по событию `my_chat_member`, если Telegram его присылает. Настройки webhook не менял |
| Тесты «со старым бэкендом» | Раньше сравнивали с последним коммитом. Теперь — с `main`, то есть с тем, что реально работает у клиентов |
