## Как включить (когда волна будет готова)

1. На GitHub слить ветку `stage8-wave1` в `main`. Витрина обновится через 1–2 минуты.
2. Открыть таблицу → Расширения → Apps Script. Заменить весь текст `Code.gs` текстом из `apps-script/Code.gs` этой ветки и сохранить.
3. **Deploy → Manage deployments → Edit (карандаш) → Version: New version → Deploy.** Без этого шага работает старая версия.
4. Настройки проекта → Script Properties → добавить `OWNER_CHAT_ID` = ваш chat id (то же число, что сейчас в `ADMIN_CHAT_IDS`; узнать можно командой `/id` у бота). `ADMIN_CHAT_IDS` не удалять.
5. `startPolling()` по-прежнему не запускать.

## Что проверить на телефоне: части 1.1 и 1.8

1. Написать боту `/start` с аккаунта, у которого нет заказов: приходит картинка PAMIR, текст с вашим именем и кнопки «Відкрити магазин», «Наші точки на ринку», «Наша курага», «Для бізнесу (опт)».
2. Написать `/start` с аккаунта, у которого есть заказ: «З поверненням, …» и кнопка «Повторити звичне». Нажать её: последний заказ лежит в корзине.
3. Отправить боту видеокружок со своего (админского) аккаунта: бот отвечает кодом `file_id`. Вставить его в панели → Налаштування → «Відеокружок перед привітанням», сохранить, снова `/start`: кружок приходит перед приветствием.
4. В панели → Налаштування заполнить «Кнопка „Написати нам“» (ваш @username), сохранить, `/start`: появилась кнопка «Написати нам».
5. `/admin` → вкладка «Адміни» → «Додати адміна» → Менеджер, отметить «Замовлення: статуси» и «Наявність і залишки» → «Створити посилання-запрошення». Открыть ссылку со второго аккаунта. Вам в бот придёт запрос: нажать «Підтвердити».
6. Со второго аккаунта: `/admin`. Видны только вкладки заказов и товаров; в карточке товара цена серая; остаток меняется.
7. С первого аккаунта: «Адміни» → «Журнал дій». Видны изменение остатка и добавление админа.
8. Сделать тестовый заказ: уведомление пришло обоим. Кнопки статусов под заказом работают у обоих.
9. «Адміни» → нажать на менеджера → снять «Доступ увімкнено» → сохранить. Со второго аккаунта `/admin` больше не открывает панель.

## Заглушки, которые нужно заменить своими данными

| Что | Где менять |
|---|---|
| Картинка приветствия (логотип на орнаменте) | панель → Налаштування → «Фото у привітанні бота» |
| Тексты приветствия UA/RU (новичку и вернувшемуся) | панель → Налаштування |
| Контакт для кнопки «Написати нам» (сейчас пусто, кнопки нет) | панель → Налаштування |
| Текст кнопки «Для бізнесу (опт)» | панель → Налаштування |
| Текст блока «Наша курага» | панель → Налаштування |

Важно: если в листе «Налаштування» уже сохранены старые тексты, они остаются как есть. В старом тексте блока «Наша курага» есть слова «без сірки» — их нужно убрать руками в панели → Налаштування.
