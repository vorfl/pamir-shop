## 3. Выпуск по шагам

Порядок важен. До открытия магазина.

1. **Проверить Script Properties** (Apps Script → Project Settings → Script
   Properties): `ALLOW_TEST_ORDERS` и `PERF_LOG` удалить, если есть;
   `USE_WEBHOOK` = `true`; `WEBHOOK_SECRET` не короче 32 случайных символов;
   `ADMIN_CHAT_IDS` — только личные id.
2. **Код.** В редакторе Apps Script:
   - `Code.gs` — заменить целиком на `apps-script/Code.gs` из ветки;
   - `Launch.gs` — заменить целиком на `apps-script/Launch.gs` из ветки;
   - **новый файл:** слева «+» → Script → имя `Stage9` → вставить
     `apps-script/Stage9.gs`. Без него пункта меню этапа 9 не будет.
3. **Deploy** → Manage deployments → карандаш → Version: New version → Deploy.
   Без этого работает старая версия.
4. **Script Properties, новые** (вписать самому): `FOP_NAME`, `FOP_IBAN`
   (UA и 27 цифр), `FOP_CODE`, `NP_API_KEY`. Можно позже: без них всё работает
   по-старому.
5. **Слить ветку `stage9a-launch` в `main`.** Фото начинают открываться по
   ссылкам только после этого, GitHub Pages обновляется 1–2 минуты.
6. Обновить страницу таблицы (появится новое меню) → **«PAMIR → Етап 9:
   застосувати дані запуску»**. Прочитать итоговое окно и лист «Етап 9 — звіт»:
   блоки «Перейменовано», «Створено», «Очищено», «чекає ціну».
   Запускать **один раз**: повторный запуск позже вернёт цены, названия и
   настройки к значениям из задания.
7. **«PAMIR → Оновити опис бота».**
8. **«PAMIR → Оновити каталог у магазині зараз».**

Не нажимать: функцию `setup()` (при `USE_WEBHOOK` не `true` отключает webhook)
и «Підготовка до запуску → Застосувати» (после этапа 9 откажется сам).
