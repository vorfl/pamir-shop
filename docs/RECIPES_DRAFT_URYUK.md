# Черновики для урюка (DRY-068): «Як їсти» и два рецепта

Это **пример**, в таблицу он не вносился. Тексты утверждает владелец: поправьте под то, как готовят у вас дома, и только потом вставляйте.
Свойств товара и пользы для здоровья здесь нет намеренно — на витрине пишем только то, что точно знаем.

## Куда вставлять

1. Меню PAMIR → «Етап 8.4: створити лист «Рецепти» і колонки» — появятся лист «Рецепти» и колонки «Як їсти (UA)», «Как есть (RU)», «Теги» в листе «Товари».
2. «Як їсти» — в строку товара DRY-068 в листе «Товари» (или в карточке товара в панели). 1–3 короткие строки.
3. Рецепты — в лист «Рецепти», по строке на рецепт. Рецепт появится в магазине, когда в колонке «Показувати» стоит `так`.

## «Як їсти» для урюка

| Колонка | Текст |
|---|---|
| Як їсти (UA) | Просто так, до чаю.<br>Замочити на ніч у воді.<br>У компот або в плов. |
| Как есть (RU) | Просто так, к чаю.<br>Замочить на ночь в воде.<br>В компот или в плов. |

Переносы строк в ячейке — Alt+Enter (в панели — обычный Enter).

## Рецепт 1. Узвар з урюка

| Колонка листа «Рецепти» | Значение |
|---|---|
| ID | `REC-001` |
| Назва (UA) | Узвар з урюка |
| Название (RU) | Узвар из урюка |
| Фото | ссылка `https://…` на фото (для витрины) или код фото от бота (только для рассылки) |
| Текст (UA) | 200 г урюку, 2 л води.<br>Урюк промити.<br>Залити водою й довести до кипіння.<br>Варити 15–20 хвилин на малому вогні.<br>Зняти з вогню й дати настоятися.<br>Цукор або мед — за смаком. |
| Текст (RU) | 200 г урюка, 2 л воды.<br>Урюк промыть.<br>Залить водой и довести до кипения.<br>Варить 15–20 минут на малом огне.<br>Снять с огня и дать настояться.<br>Сахар или мёд — по вкусу. |
| Товари | `DRY-068` |
| Показувати | `так` |

## Рецепт 2. Плов з урюком

Ингредиенты из магазина: урюк, зира, смесь для плова. Впишите их настоящие ID из листа «Товари» (в примере ниже они условные).

| Колонка листа «Рецепти» | Значение |
|---|---|
| ID | `REC-002` |
| Назва (UA) | Плов з урюком |
| Название (RU) | Плов с урюком |
| Фото | ссылка или код фото |
| Текст (UA) | *Напишите свой семейный рецепт: сколько риса, мяса, моркви й цибулі, коли класти урюк і зіру.* |
| Текст (RU) | *Напишите свой семейный рецепт: сколько риса, мяса, моркови и лука, когда класть урюк и зиру.* |
| Товари | `DRY-068, SPC-001, SPC-004` — замените на свои ID урюка, зиры и смеси для плова |
| Показувати | `ні`, пока текст не готов; потом `так` |

Пропорции и время для плова я не подставлял: рецепт семейный, и выдуманные цифры здесь хуже, чем их отсутствие.

## Что увидит покупатель

- В карточке урюка — блок «Як їсти» и ссылки «Рецепти з цим товаром».
- На главной — блок «Рецепти».
- На экране рецепта — фото, текст и товары-ингредиенты с кнопкой «Додати інгредієнти в кошик». В корзину попадают только товары, которые есть в наличии; про остальные — короткое сообщение.

## Рассылка рецепта

Панель → Розсилка → «Шаблон «Рецепт»» → кнопка с названием рецепта. Подставятся короткий текст, фото и кнопка «Відкрити рецепт». Дальше как обычно: «тільки мені» → проверка → отправка.
